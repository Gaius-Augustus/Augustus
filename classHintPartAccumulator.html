Detailed Description

exonpart hint terms of an exon for a fixed exon end and a decreasing exon begin

The Viterbi loops of ExonModel and UtrModel try all exon begins for one exon end in decreasing order. Instead of scanning all hints of the range for every begin (O(#begins * #hints)), this class updates the hint terms incrementally as the begin moves left (O(#begins + #hints)). The terms are those of the hint loops in ExonModel::notEndPartEmiProb and UtrModel::notEndPartEmiProb:

  • contained parts (start >= b, end <= E): bonus
  • parts ending in the exon (b <= end <= E): counted per type
  • endInExonRule: exonparts with start < b <= end <= E: sqrt(bonus)
  • startInExonRule: exonparts with b <= start <= E < end: sqrt(bonus) Exact exon/CDS/UTR matches are rare and are kept in list order for the caller.
